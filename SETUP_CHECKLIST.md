# Setup Checklist - Ecomin Connector and Forms

Use this checklist to ensure your app is properly set up and ready for development or deployment.

## ✅ Initial Setup

### Prerequisites
- [ ] Node.js (v18+) installed - Check with `node --version`
- [ ] npm or yarn installed - Check with `npm --version`
- [ ] Shopify CLI installed - Check with `shopify version`
- [ ] Shopify Partner account created
- [ ] Git installed (for version control)

### Project Setup
- [ ] Repository cloned or downloaded
- [ ] Navigate to project directory: `cd ecomin-connector-and-forms`
- [ ] Dependencies installed: `npm install`
- [ ] No installation errors

## 🔐 Shopify Configuration

### Partner Dashboard
- [ ] Logged into [Shopify Partners Dashboard](https://partners.shopify.com/)
- [ ] New app created manually
- [ ] App name set: "Ecomin Connector and Forms" (or your preferred name)
- [ ] API key obtained
- [ ] API secret obtained
- [ ] Development store created (optional but recommended)

### App Settings
- [ ] App URL configured (initially https://localhost)
- [ ] Allowed redirection URLs added:
  - [ ] `https://localhost/auth/callback`
  - [ ] `https://localhost/auth/shopify/callback`
  - [ ] `https://localhost/api/auth/callback`
- [ ] OAuth scopes selected (or will be set via config)

## ⚙️ Environment Configuration

### Environment Files
- [ ] `.env` file created from `.env.example`
- [ ] `SHOPIFY_API_KEY` set with your API key
- [ ] `SHOPIFY_API_SECRET` set with your API secret
- [ ] `SCOPES` configured (default should be fine)
- [ ] `SHOPIFY_APP_URL` set (https://localhost for development)
- [ ] `DATABASE_URL` set (default: file:./dev.sqlite)
- [ ] `.env` file added to `.gitignore` (already done)

### Shopify App Configuration
- [ ] `shopify.app.toml` reviewed
- [ ] App name matches your preference
- [ ] Scopes match requirements
- [ ] Webhook URLs configured

## 🗄️ Database Setup

### Prisma Setup
- [ ] Prisma client generated: `npm run prisma:generate`
- [ ] No generation errors
- [ ] Database schema pushed: `npm run prisma:push`
- [ ] Database file created (`dev.sqlite` or similar)
- [ ] Database files added to `.gitignore` (already done)

### Verify Database
- [ ] Can access database file
- [ ] Tables created (Session, EcominCredentials)

## 🚀 Development Server

### First Run
- [ ] Development server started: `npm run dev`
- [ ] Shopify CLI creates tunnel successfully
- [ ] Browser opens automatically
- [ ] No critical errors in console
- [ ] App URL generated by Shopify CLI

### App Installation
- [ ] App installed on development store
- [ ] OAuth flow completed successfully
- [ ] Redirected to app dashboard
- [ ] Dashboard loads without errors

## 🐛 Troubleshooting

If you encounter issues, check:
- [ ] Node.js version is 18 or higher
- [ ] All dependencies installed correctly
- [ ] Environment variables set correctly
- [ ] Database generated without errors
- [ ] No port conflicts (port 3000)
- [ ] Shopify CLI is up to date
- [ ] Internet connection active

### Common Fixes
```bash
# Clean install
rm -rf node_modules package-lock.json
npm install

# Regenerate Prisma
npm run prisma:generate

# Reset database
rm -f prisma/*.db
npm run prisma:push

# Kill port 3000 (if in use)
lsof -ti:3000 | xargs kill -9  # macOS/Linux
```
